# survival-crafting: acceptance scenarios

1. Gathering pays a recipe cost once and unlocks a meaningful survival choice. Record the fixture, action, expected result and observed result.
2. Full inventory, insufficient materials and simultaneous crafting cannot create negative resources. Record the fixture, action, expected result and observed result.
3. Death/restart semantics and resource respawn policies are explicit. Record the fixture, action, expected result and observed result.

Run the smallest relevant scenario in the real engine/browser, then the neighboring lifecycle path.
For an existing project, compare before/after using the same fixture. A document validator or mocked API does not verify the engine behavior. Mark unavailable runtimes as untested; include the command or manual steps another developer can run.
